# CDC: Change Data Capture

Material gratuito do QG da Engenharia de Dados. Você recebeu porque comentou **CDC**.

## Como usar este material

1. Abra o arquivo [cdc-change-data-capture.pdf](cdc-change-data-capture.pdf) → clique em **Download** se quiser guardar
2. Leia na ordem → uma forma de CDC por slide
3. Veja o exemplo de CDC por timestamp em [cdc_timestamp.sql](cdc_timestamp.sql)

## O que tem nos slides

→ Carga full x CDC
→ CDC por timestamp
→ CDC por trigger
→ CDC por log (Debezium + Kafka)
→ Tabela comparando as 3 formas
→ Ferramentas do mercado

## Resumo em uma frase

Timestamp para começar → log quando precisar de delete e tempo real.
